Day-01 初识 C 语言

1. 注释 (Comments)

注释是在程序指定位置添加的说明性信息，用于解释代码含义、标注功能或临时屏蔽代码。

简单理解：给程序员看的 “代码说明书”，编译器会直接忽略，不影响程序运行。

1.1 注释的核心特点

  • 不参与编译：注释内容仅作为文本存在。
  • 提升可读性：合理的注释是团队协作和后期维护的基石。

1.2 C 语言注释的两种写法

💡 开发工具快捷键 (VS Code/Visual Studio):

  • 注释: Ctrl + K, Ctrl + C
  • 取消: Ctrl + K, Ctrl + U (或 Ctrl + / 切换)

2. 关键字 (Keywords)

关键字（保留字）是被 C 语言赋予特殊涵义的英文单词，具有以下特征：

  • 全小写：C 语言严格区分大小写，int 是关键字，Int 则不是。
  • 专用性：不能用作变量名、函数名等标识符。
  • 高亮显示：编辑器通常会将其标记为特定颜色。

C 语言常用核心关键字

关键字 作用说明 示例场景
int 定义整型变量 / 函数返回值 int num = 5;
char 定义字符型变量 char ch = 'A';
float 定义单精度浮点型变量 float pi = 3.14f;
double 定义双精度浮点型变量 double price = 9.99;
if / else 条件判断语句 if(num > 0) { ... }
for 循环语句 for(int i=0; i<10; i++)
return 函数返回值 return 0;
void 表示“无类型”（如无返回值） void printInfo() { ... }

3. 常量 (Constants)

常量是指在程序执行过程中，其值不能改变的数据。

3.1 常量分类

  • 字符常量：单引号括起来的单个字符，如 'A', '9'。
  • 字符串常量：双引号括起来的文本，如 "Hello", "中国"。

3.2 实型（浮点）常量细节

  • .93 等同于 0.93
  • 18. 等同于 18.0
  • 科学计数法：1.234E6 代表
  • 注意：1.234*10^6 是代码计算表达式，不是常量写法。

4. 变量 (Variables)

变量是内存中的一个存储区域，在程序执行过程中其值可以发生改变。

4.1 变量的定义

格式： 数据类型 变量名; 或 数据类型 变量名 = 初始值;

4.2 变量使用的注意事项

  1. 只能存一个值：新值覆盖旧值。
  2. 作用域限制：变量只在定义的 {} 代码块内有效。
  3. 不能重复定义：同一作用域内不能有两个同名变量。
  4. 初始化：使用前必须赋值（否则可能是垃圾值）。

3. 标识符 (Identifiers)

用于给变量、函数、数组等命名的字符序列。

3.1 强制命名规则

  1. 只能由 字母 (A-Z, a-z)、数字 (0-9)、下划线 (_) 组成。
  2. 不能以数字开头。
  3. 不能是关键字。
  4. 严格区分大小写。

3.2 行业命名规范 (软性建议)

  • 小驼峰 (CamelCase) -> 适用于变量、函数

  • 单单词：name

  • 多单词：firstName, studentAge (首字母小写，后续单词首字母大写)

  • 大驼峰 (PascalCase) -> 在 C 语言中常用于结构体定义或自定义类型

  • Student, CarInfo

  • 下划线命名法 (Snake_Case) -> C 语言中最常见（特别是 Linux 风格）

  • first_name, get_student_info

2. 数据类型转换

2.1 隐式转换 (Type Promotion)

概念：把一个取值范围小的数据，自动转换成取值范围大的数据。

两条核心规则：

  1. 小变大：取值范围小的类型与取值范围大的类型运算时，小的会自动提升为大的，再进行计算。
  2. 整型提升：short, char 类型的数据在运算时，会先自动提升为 int，再进行计算。

2.2 强制转换 (Type Casting)

概念：把一个取值范围大的数据，赋值给取值范围小的变量（可能会丢失精度）。

格式： 目标数据类型 变量名 = (目标数据类型) 被强制转换的数据;

2.3 字符相加

原理：char 类型底层存储的是 ASCII 码值。参与算术运算时，会先提升为 int 类型（即其对应的 ASCII 值）。

常见 ASCII 码：

  • 'a' = 97
  • 'A' = 65
  • '0' = 48

3. 自增自减运算符 (++ / --)

符号 作用 说明
++ 自增 变量值加 1
-- 自减 变量值减 1

使用规则：

  1. 单独使用时：++i 和 i++ 结果一样，都是变量加 1。
  2. 参与运算时：
  • 前置 (++i)：先 +1，再运算（先变后用）。
  • 后置 (i++)：先运算，再 +1（先用后变）。

7. 三元运算符 (Ternary Operator)

这是 C 语言中唯一的一个三元运算符（需要三个操作数）。

格式： 关系表达式 ? 表达式1 : 表达式2;

执行流程：

  1. 计算关系表达式的值。
  2. 如果值为真 (非0)，运算结果取表达式1的值。
  3. 如果值为假 (0)，运算结果取表达式2的值。

8. 逗号运算符 (Comma Operator)

逗号运算符用于将多个表达式连接在一起。

  • 执行顺序：从左到右依次执行每个表达式。
  • 最终结果：整个逗号表达式的值，是最后一个表达式的值。
  • 优先级：在 C 语言所有的运算符中优先级最低。

格式： (表达式1, 表达式2, ... , 表达式n)

9. 运算符优先级 (Operator Precedence)

在 C 语言中，当一个表达式中出现多个运算符时，优先级决定了运算执行的顺序。

核心口诀（从高到低）：

括号成员第一，全体单目第二，乘除余三，加减四，移位五，关系六，等于七，位运算八，逻辑九，三目十，赋值十一，逗号最后。

8-10 & ^ ` ` 位运算符
11 && 逻辑与 从左到右
12 ` `

14 = += -= 等 赋值运算符 从右到左 ⬅️

⚠️ switch 使用核心注意事项

  1. 表达式类型限制：
  • switch(表达式) 中的结果必须是 整型 (int, short, long, char)。
  • 不能是浮点型 (float, double) 或字符串。
  1. case 穿透现象：

  • 利用穿透：可以利用这个特性处理多个值对应相同逻辑的情况（如：case 1, case 2, case 3 都打印 “工作日”）。
  1. default 的位置：
  • default 可以写在任意位置，但习惯上写在最后。如果不写在最后，也需要加 break。

Day-06 数组 (Array)

1. 数组的定义和初始化

1.1 什么是数组

  • 定义: 数组是一种容器，可以用来存储同种数据类型的多个值。
  • 特点:
    1. 连续空间: 数组在内存中占据一段连续的空间。
    2. 固定大小: 数组一旦定义，长度就固定了，不可动态改变。

1.2 定义格式

数据类型 数组名[长度];

1.3 数组初始化

初始化是指在定义数组的同时给它赋值。

初始化方式 代码示例 内存状态 (假设 int 占 4 字节)
完全初始化 int arr[3] = {10, 20, 30}; [10, 20, 30]
部分初始化 int arr[5] = {10, 20}; [10, 20, 0, 0, 0] (未赋值部分自动补默认值)
省略长度 int arr[] = {1, 2, 3}; 长度自动定为 3

⚠️ 默认值规则 (部分初始化时):

  • 整数 (int/short): 补 0
  • 小数 (float/double): 补 0.0
  • 字符 (char): 补 '\0' (ASCII 码为 0 的空字符)

2. 数组中的元素访问

2.1 索引 (Index)

  • 数组中的每个元素都有一个编号，称为索引（或下标）。
  • 规律: 从 0 开始，连续递增。最后一个元素的索引是 长度 - 1。

2.2 访问与修改

  • 格式: 数组名[索引]

3. 数组的遍历

遍历是指把数组中的所有元素，从头到尾都访问一遍。

3.1 动态计算数组长度 (核心技巧)

在 C 语言中，sizeof 运算符可以计算变量占用的字节大小。

  • 公式: 数组长度 = sizeof(数组名) / sizeof(数组首元素);

4. 内存中的数组

4.1 内存地址规则

  • 地址展示: 内存地址通常用十六进制表示（如 0x0061FF10）。
  • 连续性: 数组在内存中是连续存储的。

4.2 寻址原理

如果 int 占 4 个字节，且 arr[0] 的地址是 1000：

  • arr[0] -> 1000
  • arr[1] -> 1004 (1000 + 4)
  • arr[2] -> 1008 (1004 + 4)

5. 数组常见问题 (易错点)

5.1 数组越界 (Out of Bounds)

  • 现象: 访问了数组索引范围之外的空间。
  • 后果: 数据错乱、程序崩溃 (Segfault)，甚至修改了其他变量的值（非常危险）。

5.2 直接打印数组名

  • 在 C 语言中，直接 printf("%d", arr) 不会打印数组的内容。
  • arr 数组名代表的是数组的首地址。要看内容必须使用循环遍历。定义处的arr表示的是完整数组，函数中的arr只是表示一个变量，用来记录数组的首地址值

5.3 长度不可变

  • 数组定义后，无法扩容。如果需要更长的数组，只能重新定义一个新的，并将数据复制过去。

6. 数组算法题

  • 1.求最值
  • 已知数组元素为 {11,2,44,44,67};求数组的最大值
  • 2.数组求和
  • 生成十个1-100之间的随机数存入数组，并求和
  • 3.反转数组
  • 键盘录入5个数据并存入数组，并遍历数组，反转数组，再次遍历
  • 4.打乱数组
  • 键盘录入5个数据并存入,然后打乱数组顺序
  • 5.顺序查找
  • 基本查找、顺序查找就是从数组0开始,依次往后查找，如果找到了，就会返回数据对应的索引，否则返回-1。
  • 6.二分查找
  • 前提是数组数据必须是有顺序的，每次排除一半的查找范围

  • 格式: 数据类型* 变量名

  • **指针的作用:**查询\存储数据

  • 指针的使用细节:

2.指针的第一个作用(操作其他函数中的变量)

**交换变量中记录的值:**定义两个变量，要求交换变量中记录的值，注意交换的代码写在函数swap中
