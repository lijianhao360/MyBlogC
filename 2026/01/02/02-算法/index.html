NOT1: 数组

1.二分查找

难度：简单

给定一个 n 个元素有序的（升序）整型数组 nums 和一个目标值 target ，写一个函数搜索 nums 中的 target，如果 target 存在返回下标，否则返回 -1。

你必须编写一个具有 O(log n) 时间复杂度的算法。

  • 示例 1:
    输入: nums = [-1,0,3,5,9,12], target = 9
    输出: 4
    解释: 9 出现在 nums 中并且下标为 4

  • 示例 2:
    输入: nums = [-1,0,3,5,9,12], target = 2
    输出: -1
    解释: 2 不存在 nums 中因此返回 -1

  • 提示:
  1. 你可以假设 nums 中的所有元素是不重复的。
  2. n 将在 [1, 10000] 之间。
  3. nums 的每个元素都将在 [-9999, 9999] 之间。

2.移除元素

给你一个数组 nums 和一个值 val，你需要 原地 移除所有数值等于 val 的元素。元素的顺序可能发生改变。然后返回 nums 中与 val 不同的元素的数量。

假设 nums 中不等于 val 的元素数量为 k，要通过此题，您需要执行以下操作：

  • 更改 nums 数组，使 nums 的前 k 个元素包含不等于 val 的元素。nums 的其余元素和 nums 的大小并不重要。
  • 返回 k。

如果所有的断言都通过，你的解决方案将会通过。

  • 示例 1：
    输入： nums = [3,2,2,3], val = 3
    输出： 2, nums = [2,2,_,_]
    解释： 你的函数应该返回 k = 2，并且 nums 中的前两个元素均为 2。
    你在返回的 k 个元素之外留下了什么并不重要（因此它们并不计入评测）。

3. 有序数组的平方

给你一个按 非递减顺序 排序的整数数组 nums，返回 每个数字的平方 组成的新数组，要求也按 非递减顺序 排序。

  • 示例 1
  • 输入：nums = [-4,-1,0,3,10]
  • 输出：[0,1,9,16,100]
  • 解释：平方后，数组变为 [16,1,0,9,100]，排序后，数组变为 [0,1,9,16,100]
  • 示例 2
  • 输入：nums = [-7,-3,2,3,11]
  • 输出：[4,9,9,49,121]
  • 常见错误
  1. 数组定义语法错误：int num[] = [numsSize]; 不是C语言合法写法
  2. 未按题目要求分配内存：必须用 malloc 动态申请内存
  3. 缺少返回值：函数没有 return 数组
  4. 未设置返回长度：必须给 *returnSize 赋值
  5. 变量命名/格式不规范

一、螺旋矩阵的核心应用场景

螺旋矩阵不只是算法题，在工程和开发中非常实用：

  1. LED 点阵/显示屏
    8×8、16×16 点阵屏用螺旋顺序点亮 LED，实现文字/图案滚动显示（嵌入式开发常用）。
  2. 游戏开发
    环形地图生成、贪吃蛇移动路径、迷宫边界填充、游戏道具顺时针排布。
  3. 图像处理
    图片像素的环形遍历、图像边缘检测、图片旋转/裁剪的边界填充。
  4. 数据可视化
    雷达图、环形图表的数据排布，环形进度条的数值填充。
  5. 算法与测试
    二维数组边界控制训练、循环嵌套逻辑测试、矩阵类算法的基准用例。
  6. 硬件控制
    机械臂环形运动路径规划、传感器环形扫描的顺序控制。

题目要求说明

  1. 返回 n×n 的二维数组
  2. *returnSize = 矩阵行数（n）
  3. *returnColumnSizes = 数组，每个元素代表每行的列数（全为 n）
  4. 所有内存必须用 malloc 分配（调用者负责 free）
  • 一、malloc 基础
  1. 含义
    malloc 是 C 语言手动堆内存申请函数，全称内存分配。
  2. 核心作用
    开辟堆内存，区别于普通数组的栈内存：
  • 栈内存：局部数组，函数运行结束自动销毁，无法返回；
  • 堆内存：malloc 手动申请，函数结束不会自动释放，可以正常返回给外部使用。
  1. 固定语法
  • 二、代码解析
    1. 记录矩阵行数

给外部参数赋值，告诉调用者：当前矩阵一共 n 行。

    1. 开辟每行列数的数组

malloc 开辟一块数组空间，存放每行的列数；
n阶矩阵每行都是 n 列，统一赋值，用于告知系统矩阵列信息。

    1. 开辟二维矩阵内存
  • 先申请行指针数组：存放每一行的地址；
  • 再循环为每一行单独申请空间；
  • 最终拼成完整 n*n 二维数组，内存持久有效，支持 return 返回。
  • 三、重点总结
  1. 写LeetCode C语言返回二维数组，必须用 malloc，否则数组销毁、报错；
  2. returnSize 传总行数，returnColumnSizes 存每行列数，是题目固定格式；
  3. 二维数组开辟两步：先开行指针、再开每一行；
  4. malloc 只负责申请内存，用完由题目内部 free 释放，不用自己写。
