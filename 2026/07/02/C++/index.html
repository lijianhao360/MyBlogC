第01章 C++语言开始

1.1 输入输出

  • 1.标准输入对象 cin
  • cin 可以理解为结构体变量
  • 用于输入数据，等价于c语言的scanf
  • 使用 “>>” 来关联多个变量
  • std::cin 可以把std理解为结构体变量，”::” 理解为”.”，就是结构体访问成员名
  • std 的缩写为: standard，可以把他理解为一个容器。
  • 2.标准输出对象 cout
  • cout 可以理解为结构体变量
  • 用于输出数据，等价于c语言的printf
  • 使用 “<<” 来关联多个变量
  • std::cout 可以把std理解为结构体变量，”::” 理解为”.”，就是结构体访问成员名

  • cerr 可以理解为结构体变量
  • 用于输出错误提示，等价于c语言的printf
  • 使用 “<<” 来关联多个变量
  • std::cerr 可以把std理解为结构体变量，”::” 理解为”.”，就是结构体访问成员名
  • 4.标准日志对象 clog
  • clog 可以理解为结构体变量
  • 用于输出日志，等价于c语言的printf
  • 使用 “<<” 来关联多个变量

  • 7.命名空间
  • c++中有很多类名(结构体类型)，c++标准中封装了太多的c++类 (结构体类型)，是为了解决系统定义的类和用户定义的类重名，设计出来一个概念，命名空间，用来把这些类加上一个限定名，这个名就是命名空间

第02章 变量与数据类型

2.1 基本内置类型

C++定义了一套包括算术类型(arithmetic type)和空类型(void)在内的基本数据类型。其中算术类型包含了字符、整型数、布尔值和浮点数。空类型不对应具体的值，仅用于一些特殊的场合，例如最常见的是，当函数不返回任何值时使用空类型作为返回类型。

  • 1.算术类型
  • 算术类型分为两类：整型(integral type，包括字符和布尔类型在内)和浮点型。
    • bool 类型，真和假，真为1，假为0，true和false
    • char 类型，一个字节的数
    • wchar_t ，宽字符16位宽
    • char16_t，Unicode字符，16位宽
    • char32_t，Unicode字符, 32位宽
    • short：16位宽的整数
    • int ，32位宽的整数
    • long ，32位系统(32位位宽)，64位系统(64位宽)
    • long long，64位宽的整数
    • float ，32位宽的实数，小数点后保留6位
    • double，64位宽的实数,小数点后保留15位
    • long double，128位宽的实数,小数点后保留19位
  • 2.布尔类型
  • 是真和假，C语言使用0为假，非0为真
  • c++ 使用 true 为真，false 为假

5.4 内联函数

  • 1.内联函数
  • 在函数前加上关键字inline，说明这个函数是内联函数
  • 正常情况下，调用函数比直接调用代码要慢，因为函数的调用要多余产生调用指令和保存与恢复栈操作
  • 内联函数可以避免这种开销。因为内联函数是就地展开代码，不再产生调用跳转指令，也不需要保存与恢复，执行效率更高
  • 内联函数一般是用在函数比较小的情况下使用，如果函数体过大，则不建议使用

第06章 类与对象(封装)

6.1 面向对象的编程

  • 1.面向对象思想
  • 1.目的:实现软件设计的产业化。
  • 2.观点:自然界是由实体(对象)所组成。
  • 3.程序设计方法:使用面向对象的观点来描述模仿并处理现实问题。
  • 4.要求:高度概括、分类和抽象。
  • 2.抽象
  • 抽象是对具体对象(问题)进行概括、抽出这一类对象的公共性质并加以描述的过程。
  • 数据(属性)抽象
  • 代码(功能)抽象
  • 3.封装
  • 将抽象出的数据成员、代码成员相结合，将他们视为一个整体。
  • 目的是增强安全性和简化编程，使用者不必了解具体的实现细节，而只需要通过外部接口，以特定的访问权限，来使用类的成员。

6.2 面向对象的类

  • 1.C++中的类
  • 类是具有相同属性和行为的一组对象的集合，它为属于该类的全部对象提供了统一的抽象描述，其内部包括属性和行为两个主要部分。
  • 利用类可以实现数据的封装，隐藏，继承与派生。
  • 利用类易于编写大型复杂程序，其模块化程度比采用函数更高。
  • 图形界面编程一般是使用面向对象的语言实现(c++,python,java,go)
  • 2.类的声明形式
  • 类是一种用户自定义类型，声明形式:

  • 公有类型成员
    在关键字public后面声明，它们是类与外部的接口，任何外部函数都可以访问公有类型数据和函数。

  • 私有类型成员
    在关键字private后面声明，只允许本类中的函数访问，而类外部的任何函数都不能访问

  • 保护类型
    与private类似，其差别表现在继承与派生时对派生类的影响不同，在讲继承时再说明。

  1. public（公有）：类外部代码、子类都可以直接访问，作为对外接口
  2. private（私有，class默认权限）：只有本类内部能访问，外部、派生类都无法直接访问
  3. protected（保护）：本类内部 + 子类（继承）可以访问，外部不能访问

小知识点：class定义的类，默认访问权限是private。

6.3 构造函数和析构函数

  • 1.构造函数

  • 构造函数的作用是在对象被创建时使用特定的值构造对象，或者说将对象初始化为一个特定的状态。

  • 在对象创建时由系统自动调用。

  • 如果程序中未声明，则系统自动产生出一个默认形式的构造函数

  • 允许为内联函数、重载函数、带默认形参值的函数

  • 函数名和类名一样的函数，且没有返回值

  • 笔记总结

  1. 特征：函数名 = 类名，无返回值
  2. 时机：创建对象自动执行，用来初始化成员变量
  3. 规则：自己不写构造函数，编译器会提供默认无参构造；可以重载多个构造函数
  • 2.代码
  • 3.默认参数构造函数
  • 可以匹配无参的构造函数，也可以匹配有参的构造函数
  • 4.拷贝构造函数
  • 拷贝构造函数是一种特殊的构造函数，其形参为本类的对象引用。
  • 调用copy构造函数的三种情况
    • 当用类的一个对象去初始化该类的另一个对象时系统自动调用拷贝构造函数实现拷贝赋值。
    • 若函数的形参为类对象，调用函数时，实参赋值给形参，系统自动调用拷贝构造函数。
    • 当函数的返回值是类对象时，系统自动调用拷贝构造函数。
  • 运行输出
  • 5.析构函数
  • 提取文字（析构函数PPT）
  • 完成对象被删除前的一些清理工作。
  • 在对象的生存期结束时系统自动调用它，然后再释放此对象所属的空间。
  • 如果程序中未声明析构函数，编译器将自动产生一个默认的析构函数。
  • 在构造函数前加上 ~ 表示的是析构函数。
  • 有多少个对象被创建，就有多少个析构函数被自动执行。
  • 析构函数调用顺序是和构造函数相反的顺序(入栈顺序是构造函数顺序，出栈顺序是析构函数顺序)。
  • 补充知识点（考点）
  1. 析构函数特点：没有返回值、没有参数、不能重载；名字是~类名()。
  2. 用途：释放类内部new申请的堆内存、关闭文件/外设等资源。
  3. 栈对象：先构造的后析构，后构造的先析构，栈后进先出。

  1. 析构函数写法：~类名()，不能带参数，没有返回值，不能重载
