1.GPIO输出与点灯

  • 1.GPIO简介

GPIO是通用输入输出端口的简称，简单来说就是STM32可控制的引脚，STM32芯片的GPIO引脚与外部设备连接起来，从而实现与外部通讯、控制以及数据采集的功能。所有的GPIO引脚都有基本的输入输出功能。

最基本的输出功能是由STM32控制引脚输出高、低电平，实现开关控制，如把GPIO引脚接入到LED灯，那就可以控制LED灯的亮灭，引脚接入到继电器或三极管，那就可以通过继电器或三极管控制外部大功率电路的通断。

最基本的输入功能是检测外部输入电平，如把GPIO引脚连接到按键，通过电平高低区分按键是否被按下。

  • 2.IO复用和复用功能重映射
    IO复用 - 同一个IO引脚具备多个不同的功能，既可以被用户编程，也可以给芯片上的其他模块使用

复用功能重映射 - 将冲突的复用功能移动到备用的引脚上去

  • 3.四种输出模式
推挽 开漏
通用 通用输出推挽 通用输出开漏
复用 复用输出推挽 复用输出开漏
  • 1.推挽和开漏

推挽输出 - 一对MOS管交替导通，对外输出低电压或高电压
开漏输出 - PMOS保持关断，可以对外输出低电压或高阻抗

  • HAL库 UART简单收发实验 CubeMX操作步骤（铁头山羊）
    1.配置RCC时钟**
  • RCC → High Speed Clock(HSE)，选择外部晶振Crystal/Ceramic Resonator。
  • 配置系统时钟树，把系统主频配置到芯片最大主频。

2.配置调试接口（必须配，否则下载后芯片锁死）

  • SYS → Debug，选择Serial Wire（SWD调试）。

3.配置USART外设

  • 进入Connectivity，选择要使用的USART（比如USART1）。
  • Mode选择：Asynchronous 异步模式。
  • 硬件自动分配TX、RX引脚；不要改引脚。
  • 参数配置：波特率115200，数据位8bit，无校验位，停止位1bit。

4.开启全局中断（串口中断方式收发才需要）

  • NVIC Settings标签页，勾选 USARTx global interrupt，保持中断优先级默认即可。

5.工程生成配置

  • Project Manager → Project，填写工程名、选择保存路径，Toolchain选择MDK‑ARM。

  • Project Manager → Code Generator：勾选生成外设初始化.c/.h文件，每个外设独立文件。

  • 点击GENERATE CODE生成工程。

  • CubeMX完成后，MDK里面核心代码要点

  1. 轮询收发：HAL_UART_Transmit()、HAL_UART_Receive()，阻塞式。
  2. 中断接收：HAL_UART_Receive_IT()开启中断接收；回调函数HAL_UART_RxCpltCallback()处理收到的数据。
  3. 不要忘记在main中调用 HAL_UART_Init(&huart1)（CubeMX生成代码已经自动调用）。

注意：简单收发实验两种方案：轮询（简单但阻塞）、中断（推荐，非阻塞）。CubeMX只做引脚、时钟、中断使能配置，接收逻辑需要自己写。

  • STM32 HAL库 PWM互补输出 两个LED互补呼吸（铁头山羊）

    普通PWM是单路输出；互补PWM：CH1 和 CH1N 两路引脚输出完全相反波形，一个亮另一个灭。
    适合两个LED：CH1接LED1，CH1N接LED2；LED1亮度上升，LED2亮度下降，两者互补。

-CubeMX配置步骤（互补PWM）

  1. 选定时器，时钟源：Internal Clock内部时钟
  2. Channel1：选择 PWM Generation CH1 CH1N （开启主输出+互补输出）
  3. 时基参数（系统时钟72MHz示例）
    • PSC预分频：71
    • ARR自动重装载：999
    • PWM频率 = 72M/(71+1)/(999+1) = 1000Hz
  4. PWM参数设置
    • PWM mode：PWM mode 1
    • Pulse初始CCR：0
    • CH极性：High；CH N极性：High
    • 关闭死区时间：Dead‑time 填0（LED实验不需要死区，电机驱动才需要）
  5. NVIC：不开启定时器更新中断，互补输出不需要中断
  6. 生成工程

原理：
CH1输出高，CH1N自动输出低；CH1输出低，CH1N自动输出高。
CCR变大 → CH1占空比变大(LED1变亮)，CH1N占空比变小(LED2变暗)
CCR变小 → CH1占空比变小(LED1变暗)，CH1N占空比变大(LED2变亮)

  • 完整代码（正弦曲线互补呼吸，math.h版本）
  • 简易版本（不用math.h，方向变量实现互补呼吸）

现象：LED1慢慢变亮同时LED2慢慢变暗；LED1慢慢变暗同时LED2慢慢变亮，两个LED亮度总和不变。

  • 关键API
  1. HAL_TIM_PWM_Start(&htim1,TIM_CHANNEL_1); 启动主PWM通道CH1
  2. HAL_TIMEx_PWMN_Start(&htim1,TIM_CHANNEL_1); 启动互补通道CH1N，互补输出必须调用
  3. __HAL_TIM_SET_COMPARE() 修改CCR，硬件自动同步更新CH1和CH1N两路波形
  • 重点笔记
  1. 必须选择PWM Generation CH1 CH1N，只选CH1不会出现互补引脚。
  2. 一定要调用HAL_TIMEx_PWMN_Start，否则互补引脚没有输出。
  3. LED硬件注意：CH1、CH1N输出引脚分别接两个LED。
  4. 死区时间Dead‑time：LED实验设置0；电机、逆变器才需要设置死区。
  5. 用sin正弦函数效果：亮度平滑柔和；dir加减方式：简单，不需要math库。

  • 只调用HAL_TIM_PWM_Start，忘记HAL_TIMEx_PWMN_Start，互补引脚无波形
  • CubeMX没有选CH1+CH1N，只有普通PWM，找不到互补引脚
  • 开启死区时间不为0，LED亮度异常

__HAL_TIM_CLEAR_FLAG：清除定时器的事件标志位。

  • 一、CubeMX详细操作步骤
    1. RCC 外部晶振配置
  1. 点开 System Core → RCC
  2. High‑Speed Clock (HSE)：选择 Crystal/Ceramic Resonator（外部晶振）
  3. 进入 Clock Configuration 时钟树页面
  4. 根据你的芯片（F1/F4）配置系统主频，例如F407配置168M，F103配置72M，保证定时器输入时钟准确。
    1. TIM定时器输入捕获配置（以TIM1举例）

      目标：定时器计数频率 = 1MHz，CNT每+1就是1us

  1. 点开 Timers → TIM1
  2. Channel1：选择 Input Capture direct mode（通道1直接输入捕获）
    • CH1 Polarity Selection：Rising edge 上升沿捕获（Echo上升沿，记录开始时刻）
  3. Channel2：选择 Input Capture direct mode
    • CH2 Polarity Selection：Falling edge 下降沿捕获（Echo下降沿，记录结束时刻）
  4. Parameter Settings 参数设置
    • Prescaler(PSC)预分频：
      • 如果定时器时钟为72MHz：PSC = 71 → 72M/(71+1)=1MHz
      • 如果定时器时钟为84MHz：PSC = 83
      • 如果定时器时钟为168MHz：PSC = 167
    • Counter Period(ARR)自动重装载值：填 0xFFFF（最大65535，足够测超声波）
    • Counter mode：Up 向上计数
  5. NVIC Settings 中断选项：TIM1 update and trigger interrupt 全部取消勾选，不开启中断，本实验轮询读标志。
  6. 确认TIM1外设时钟已经开启。
    1. Trig触发引脚GPIO配置（PA0）
  1. System Core → GPIO → PA0
  2. GPIO mode：Output Push Pull 推挽输出
  3. GPIO output level：Low 初始低电平
  4. GPIO speed：High高速
    1. 工程生成设置
  1. Project Manager → Project
    • Project Name：工程名字
    • Toolchain/IDE：MDK‑ARM V5
  2. Project Manager → Code Generator
    • ✔ Generate initialization code only（仅生成初始化代码）
  3. 右上角 GENERATE CODE 生成工程。

    打开main.c

  • 三、硬件接线

  • HC‑SR04 VCC → 5V

  • HC‑SR04 GND → GND

  • HC‑SR04 Trig → PA0

  • HC‑SR04 Echo → TIM1_CH1引脚（注意！Echo接到TIM1通道1硬件引脚，不是PA0！）

  • 四、关键注意点

  1. Echo必须接TIM1_CH1硬件引脚，不能随便接普通GPIO，输入捕获必须定时器通道引脚。
  2. PSC预分频一定要算对，保证定时器计数频率1MHz，1个tick = 1微秒。
  3. 每次测量前必须清零CNT计数器，清除CC1、CC2标志位。
  4. 设置超时时间，没有回波不会死循环。
  5. 该版本为轮询，没有开启定时器NVIC中断。
