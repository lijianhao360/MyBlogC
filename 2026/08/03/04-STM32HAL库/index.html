1.GPIO输出与点灯

  • 1.GPIO简介

GPIO是通用输入输出端口的简称，简单来说就是STM32可控制的引脚，STM32芯片的GPIO引脚与外部设备连接起来，从而实现与外部通讯、控制以及数据采集的功能。所有的GPIO引脚都有基本的输入输出功能。

最基本的输出功能是由STM32控制引脚输出高、低电平，实现开关控制，如把GPIO引脚接入到LED灯，那就可以控制LED灯的亮灭，引脚接入到继电器或三极管，那就可以通过继电器或三极管控制外部大功率电路的通断。

最基本的输入功能是检测外部输入电平，如把GPIO引脚连接到按键，通过电平高低区分按键是否被按下。

  • 2.IO复用和复用功能重映射
    IO复用 - 同一个IO引脚具备多个不同的功能，既可以被用户编程，也可以给芯片上的其他模块使用

复用功能重映射 - 将冲突的复用功能移动到备用的引脚上去

  • 3.四种输出模式
推挽 开漏
通用 通用输出推挽 通用输出开漏
复用 复用输出推挽 复用输出开漏
  • 1.推挽和开漏

推挽输出 - 一对MOS管交替导通，对外输出低电压或高电压
开漏输出 - PMOS保持关断，可以对外输出低电压或高阻抗

3.UART

  • 1.串口
  • 2.校验位
  • 3.同步和异步
  • 4.UART实验部分
  • HAL库 UART简单收发实验 CubeMX操作步骤（铁头山羊）
    1.配置RCC时钟**
  • RCC → High Speed Clock(HSE)，选择外部晶振Crystal/Ceramic Resonator。
  • 配置系统时钟树，把系统主频配置到芯片最大主频。

2.配置调试接口（必须配，否则下载后芯片锁死）

  • SYS → Debug，选择Serial Wire（SWD调试）。

3.配置USART外设

  • 进入Connectivity，选择要使用的USART（比如USART1）。
  • Mode选择：Asynchronous 异步模式。
  • 硬件自动分配TX、RX引脚；不要改引脚。
  • 参数配置：波特率115200，数据位8bit，无校验位，停止位1bit。

4.开启全局中断（串口中断方式收发才需要）

  • NVIC Settings标签页，勾选 USARTx global interrupt，保持中断优先级默认即可。

5.工程生成配置

  • Project Manager → Project，填写工程名、选择保存路径，Toolchain选择MDK‑ARM。

  • Project Manager → Code Generator：勾选生成外设初始化.c/.h文件，每个外设独立文件。

  • 点击GENERATE CODE生成工程。

  • CubeMX完成后，MDK里面核心代码要点

  1. 轮询收发：HAL_UART_Transmit()、HAL_UART_Receive()，阻塞式。
  2. 中断接收：HAL_UART_Receive_IT()开启中断接收；回调函数HAL_UART_RxCpltCallback()处理收到的数据。
  3. 不要忘记在main中调用 HAL_UART_Init(&huart1)（CubeMX生成代码已经自动调用）。

注意：简单收发实验两种方案：轮询（简单但阻塞）、中断（推荐，非阻塞）。CubeMX只做引脚、时钟、中断使能配置，接收逻辑需要自己写。

  • STM32 HAL库 I2C‑OLED CubeMX配置步骤

    硬件：I2C接口OLED，SCL、SDA引脚使用芯片硬件I2C外设

  • 1.引脚配置
    1.RCC配置：选择外部高速晶振HSE，系统时钟树配置到对应主频（一般72M）
    2.SYS：Debug选择Serial Wire，开启下载调试
    3.Connectivity → 选择硬件I2C（I2C1 / I2C2）

    • I2C Mode：I2C
    • I2C Speed Mode：标准模式Standard Mode(100KHz)，OLED大多100K
    • 对应SCL、SDA引脚自动分配，若引脚不对手动改引脚
      4.GPIO不用手动配置，开启I2C外设后，CubeMX自动把引脚设置为I2C开漏复用模式

  • 2.生成工程设置
    1.Project Manager → Project：设置工程名字、存储路径
    2.Code Generator：

    • 勾选 Generate peripheral initialization as a pair of ‘.c/.h’ files per peripheral
    • 每个外设生成独立c/h文件，方便移植
      3.生成代码GENERATE CODE

  • 3.代码工程修改（重点，铁头山羊I2C‑OLED）
    1.把 oled.c、oled.h 驱动文件复制到工程目录，添加到Keil
    2.在main.c引入头文件 #include "oled.h"
    3.注意：驱动文件中hi2c句柄要和CubeMX生成的保持一致（hi2c1 / hi2c2）
    4.在main()里面，外设初始化之后while(1)之前调用 OLED_Init();
    5.while循环内调用显示函数：OLED_ShowString、OLED_ShowNum等

笔记要点：

  1. 两个函数都是阻塞式I2C，没完成传输程序会停住。
  2. DevAddress传入OLED的7位左移后的地址，常见0x78或0x7A。
  3. 数组求元素个数：sizeof(arr)/sizeof(arr[0])。
  4. 位运算 dataRcvd & (0x01 << 6)，用来取出第6位(D6)的电平状态。
  5. HAL_MAX_DELAY：无限超时，收/发不完不退出函数。
  6. 硬件I2C注意SDA/SCL外部上拉电阻。

  • 关键笔记
