第一章: 常见元器件

一、电阻

电阻是电子电路中最基础的无源元件，核心作用是限制电流大小、分配电压高低，同时还能起到分压、分流、限流、负载等作用，遵循欧姆定律（U=IR）。

  • 一、核心参数
  1. 标称阻值：电阻的标准电阻值，常用色环法（四环 / 五环）或数字直标法标注，单位为欧姆（Ω），大阻值用千欧（kΩ）、兆欧（MΩ）表示（1MΩ=1000kΩ=10⁶Ω）。
  2. 额定功率：电阻长期工作允许消耗的最大功率，超过会发热烧毁，常见小功率电阻为 1/8W、1/4W、1/2W。
  3. 精度：实际阻值与标称阻值的误差范围，普通电阻精度 ±5%、±10%，精密电阻可达 ±1% 甚至更高。
  • 二、常见类型（适合初学者）
  • 碳膜电阻：成本低、精度一般，适合普通电路。
  • 金属膜电阻：精度高、稳定性好，常用于要求较高的电路（如嵌入式开发板）。
  • 贴片电阻：体积小，表面贴装，是 PCB 板上最常见的类型。
  • 可变电阻（电位器）：阻值可手动调节，比如收音机的音量旋钮
  • 三、电阻的读取

二、电容

  • 认识电容
    电容是电子电路中三大基础无源元件之一，核心作用是储存和释放电荷，就像电路里的“小电池”，还能实现滤波、耦合、旁路、谐振等功能。

  • 一、核心原理
    电容由两个相互绝缘的导体（极板）和中间的绝缘介质构成。当两端加上电压时，极板会积累等量异种电荷；断开电源后，电荷会在极板上保存一段时间（理想状态），形成电场。

  • 二、核心参数

  1. 标称容量：电容储存电荷的能力，单位是法拉（F），常用单位为微法（μF）、纳法（nF）、皮法（pF），换算关系：
    1F = 1000000 μF = 1000000000 nF = 1000000000000 pF
  2. 额定电压：电容长期稳定工作允许的最大电压，超过这个值会击穿介质，导致电容损坏。
  3. 介质类型：决定电容的性能和适用场景，常见的有陶瓷、电解、钽电容等。
  4. 精度：实际容量与标称容量的误差范围，普通电容精度 ±20%，精密电容可达 ±1%。

  • 三、电容特性
    电容两端电压不能突变
    $I=C\cdot \mathrm{dU/dt},\quad u=\frac1C \int i\mathrm{d}t$

  • 四、各种电容

三、电感

  • 认识电感
    电感是电子电路三大基础无源元件之一，核心作用是储存磁场能量，能阻碍电流的变化（通直流、阻交流，通低频、阻高频），常用来实现滤波、扼流、谐振、储能等功能。

  • 一、核心原理
    电感的本质是绕在铁芯或磁芯上的线圈。当电流通过线圈时，会产生磁场；电流变化时，磁场也会随之变化，进而在线圈自身感应出反向电动势，阻碍电流的增减——这个特性叫做电磁感应。
    简单类比：电感就像电路里的“惯性元件”，电流想突然变大或变小，它都会“拖后腿”。

  • 二、核心参数
    电感量：衡量电感储存磁场能力的参数，单位是亨利（H），常用单位为毫亨（mH）、微亨（μH）
    换算关系：1H = 1000 mH = 1000000 μH

额定电流：电感长期工作允许通过的最大电流，超过会因发热烧毁线圈，或导致电感量下降。

第三章: 模电知识

一、半导体

  • 1.什么是半导体
    一种介于导体和绝缘体之间的材料，有时导电，有时不导电，其导电性取决于外部条件（如：温度、光照、电压等）—— 导电性可控。

  • 2.本征半导体

  1. 硅晶体在高温下，能从绝缘体变成导体，是其材料的天然物理特性，是不需要掺杂任何其他的成分。
  2. 我们将这类材料称为本征半导体。
  3. 本征激发：指在本征半导体中，由于外部的热能、光能、电场等激励下，使原本处于价带的电子被激发到导带，从而在材料内部形成：电子 + 空穴对的现象。

注意：本征半导体是电中性的！

  • 考点笔记
  • 本征半导体：纯净、无杂质的半导体（如单晶硅）
  • 本征激发：受热/光/电场，价带电子跃迁到导带，成对产生自由电子和空穴
  • 重点：虽然产生带负电电子、带正电空穴，整体不带电，保持电中性
  • 3.N型半导体

N型半导体:向硅晶体中掺杂适量的磷原子，磷原子最外层有5个电子，它会和周围的4个硅原子组成4个共价键，这样每个磷原子都可以提供1个自由电子。

  • N型半导体:电子是多子（多数载流子），空穴是少子

  • 掺杂元素:磷P（五价元素，施主杂质）

  • 重点:N型半导体整体仍然电中性，只是自由电子数量大幅增多

  • 1.纯硅已经是半导体了，为什么还要掺杂磷呢？
    能让半导体的导电性能更好，并且让半导体导电性更容易控制。

  • 2.为什么叫N型半导体？
    由于磷元素的加入，带来了更多的自由电子，使半导体中负电荷载流子的数量大幅增加，因此这种半导体被称为N型（Negative）半导体。

载流子：在导电过程中能够携带电荷并产生电流的粒子。
在金属导体中，载流子是自由电子。
在某些盐溶液中，载流子可能是正离子或负离子。

  • 3.N型半导体，几乎都是搭配P型半导体一起来使用，形成PN结（下几小节会详细讲）。

注意：N型半导体也是电中性的！

  • 考点笔记
  • 掺杂目的：提升导电性、方便控制导电能力
  • N含义：Negative，代表多数载流子是带负电的自由电子
  • 核心易错点：多了大量自由电子，但整体材料不带电，电中性
  • 实际应用：单独N型用处不大，和P型组合形成PN结，是二极管、三极管基础
  • 4.P型半导体

P型半导体：向硅晶体中掺入硼原子，硼原子最外层只有3个电子，硼原子会努力的和周围的硅原子形成共价键，并且会因为缺1个电子，形成“空穴”

  • 对于N型半导体来说，更多的载流子是电子（电子是多子，空穴是少子）
  • 对于P型半导体来说，更多的载流子是空穴（空穴是多子，电子是少子）

为什么叫P型半导体？
对于P型半导体来说，更多的载流子是空穴，空穴可认为是带正电的:正（Positive）

注意：P型半导体也是电中性的！

  • 考点笔记
    P型半导体掺杂：硼原子（三价元素，受主杂质）
    多数载流子：空穴（带正电，Positive，P型名称来源）
    少数载流子：自由电子
    易错点：P型半导体整体依然是电中性，不是带正电，只是存在大量可移动的空穴

  • 5.PN结

  • 1.当P型、N型半导体贴在一起时：

    • N区大量自由电子，会向P区扩散；P区大量空穴，会向N区扩散。
    • 在交界面附近：N区失去电子，留下正离子；P区得到电子，空穴被复合，留下负离子。
    • 交界面就形成一层空间电荷区（耗尽层），产生内建电场，电场方向：N → P。

  • 2.内建电场的作用：

    • 阻碍扩散运动：N区电子想继续跑到P区，这个电场会把电子“推回去”，阻止电子继续扩散。
    • 产生漂移运动：在内建电场作用下，少数载流子会反向移动。
    • 最后达到动态平衡：扩散的载流子数量 = 漂移的载流子数量，净电流=0，这就是零偏置下的PN结。

  • 核心一句话：

    扩散运动造就了内建电场；内建电场反过来抑制扩散，最终达到平衡。
    这个耗尽层，就是PN结的核心，也是二极管单向导电的基础。

  • 考点小结

  • 内建电场方向：N区指向P区

  • 内建电场的核心效果：阻碍多子的扩散运动

  • 平衡时：扩散电流 = 漂移电流，总电流为0

二、二极管

  • 1.了解二级管

  • 2.二极管常用功能

  • 3.关注参数
  • 正向压降(V_F)：当二极管处于正向偏置时，二极管导通所需的电压。
  • 反向漏电流(I_R)：二极管在反向偏置时流过的微小电流（通常为纳安、微安级，高温下会增大）。
  • 最大重复反向电压(V_{RRM})：二极管在反偏下，能重复承受的最大电压，超过此值可能导致损坏。
  • 最大平均整流电流(I_{AV})：二极管能够持续承受的最大电流，超过此值，二极管可能因过热而损坏。
  • 最大峰值正向浪涌电流(I_{FSM})：二极管在短时间内，能承受的瞬时大电流（如开机浪涌）。

  • 4.稳压二极管
  • 概述：稳压二极管利用了二极管的反向击穿特性，它在反向击穿后，可以将其两端电压，维持在相对恒定的值附近，它可以为电子设备提供稳定的电压，并防止过压损害。
  • 关注参数
  • 稳压值(V_Z)：稳压二极管在反向击穿区时，其两端能够维持的稳定电压，受电流和温度的影响。
  • 耗散功率(P_d)：稳压二极管能承受的最大功率，实际应用中需留有余量（通常≥30%）。
  • 最大工作电流(I_{Zmax})：稳压二极管允许长期通过的最大反向电流。
  • 最小稳压电流(I_{Zmin})：稳压二极管达到稳压效果，所需的最小反向电流。

  • 5.发光二极管
  • 关注参数
  • 正向电压$(V_f)$：LED导通时其两端的压降，与材料和颜色有关。
  • 额定正向电流$(I_f)$：LED在正常工作状态下，能够持续通过的最大电流。
  • 功率$(P_d)$：功率直接关系到发热量。功率较大的LED需要更好的散热设计。
  • 发光强度：单位是『坎德拉（cd）』，光强越大，亮度越高。
  • 发光角度：
    窄角度：15°30°，光线集中，中心光强高。
    宽角度：120°    180°，光线分散，覆盖范围广。
    工作温度：LED能够稳定运行的温度范围。
  • 6.LED限流电阻的计算
  • 为什么给LED加限流电阻

LED 在点亮后 (正向导通后)，即使电压轻微增加，电流也会急剧增大，大电流很容易烧毁 LED。

第四章: 电路

1.LDO稳压电路

  • 也就是之前的降压模块

  • 一、核心模块与元件作用

    元件 类型 功能
    Q1 PMOS管 串联调整管：通过栅极电压（UG）控制其导通电阻，调节VIN到VOUT的压降，实现稳压。
    (PMOS的S接VIN、D接VOUT，栅极电压越低，导通电阻越小)
    U1 运算放大器 误差放大器：比较“反馈电压（VFB）”与“基准电压（VREF）”，输出控制信号（UG）驱动Q1。
    VREF 电压基准源 提供稳定的参考电压，是输出电压的“基准锚点”。
    R1、R2 分压电阻 反馈网络：对VOUT分压得到VFB，将输出电压“反馈”到U1的反相端，用于闭环调节。
    C1 输出电容 1. 稳定VOUT，抑制负载突变的电压波动（提升瞬态响应）；
    2. 配合LDO环路，保证系统稳定性（避免振荡）。
    R3 负载电阻 代表LDO的输出负载（实际应用中是芯片、电路等用电设备）。

  • 二、工作原理（负反馈闭环稳压）

  1. 分压采样：输出电压VOUT经过 R1、R2 分压，得到反馈电压 VFB = VOUT * R2/(R1+R2)。

  2. 误差比较：运放 U1 将 VFB（反相端）与基准电压 VREF（同相端）比较，输出误差信号 UG。

  3. 调整管控制：UG 驱动 PMOS 管 Q1 的栅极：

    • 若 VOUT 升高 → VFB > VREF → U1 输出 UG 升高 → Q1 的栅‑源电压（VGS=VIN‑UG）减小 → Q1 导通电阻增大 → VIN 到 VOUT 的压降增大 → VOUT 回落；
    • 若 VOUT 降低 → VFB < VREF → U1 输出 UG 降低 → Q1 导通电阻减小 → VIN 到 VOUT 的压降减小 → VOUT 回升。

  4. 最终通过闭环调节，使 VFB = VREF，因此输出电压固定为：
    VOUT = VREF * (1 + R1/R2)（通过改变 R1/R2 可调整输出电压）。

  • 1.大电流功率回路（粗线部分）
    核心要求：原理图里加粗的走线（输入电容→芯片 VIN→开关管→电感→输出电容→地）必须最短、最宽。

  • 2.地平面与接地
    原理图提示 “GROUND PLANE CONSTRUCTION”，说明必须做完整的地平面或局部铺铜。
    芯片的 GND 引脚、输入 / 输出电容的负极、二极管 D1 的负极都要直接连接到地平面。
    不要在地平面上开槽或走信号线，避免切断地回流路径。

  • 3.反馈（FEEDBACK）回路
    原理图明确提示：编程电阻 R1、R2 要紧贴反馈引脚（Pin4），用最短的引线连接。
    反馈线要远离电感 L1，避免电感的磁场干扰采样信号，否则会导致输出电压不稳或纹波增大。
    反馈线单独走，不要和大电流走线并行，宽度不用太宽，细而短即可。

  • 4.电感与二极管区域
    电感 L1 和续流二极管 D1 是高频开关的核心元件，它们的走线要短且粗。
    尽量让 L1 和 D1 靠近芯片的 OUTPUT 引脚，减少高频环路面积，降低 EMI 干扰。

  • 5.使能引脚（ON/OFF）
    如果使用该引脚控制芯片开关，它的走线属于小信号，也要远离大电流路径和电感，避免误触发。
