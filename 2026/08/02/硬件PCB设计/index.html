第一章: 常见元器件

一、电阻

电阻是电子电路中最基础的无源元件，核心作用是限制电流大小、分配电压高低，同时还能起到分压、分流、限流、负载等作用，遵循欧姆定律（U=IR）。

  • 一、核心参数
  1. 标称阻值：电阻的标准电阻值，常用色环法（四环 / 五环）或数字直标法标注，单位为欧姆（Ω），大阻值用千欧（kΩ）、兆欧（MΩ）表示（1MΩ=1000kΩ=10⁶Ω）。
  2. 额定功率：电阻长期工作允许消耗的最大功率，超过会发热烧毁，常见小功率电阻为 1/8W、1/4W、1/2W。
  3. 精度：实际阻值与标称阻值的误差范围，普通电阻精度 ±5%、±10%，精密电阻可达 ±1% 甚至更高。
  • 二、常见类型（适合初学者）
  • 碳膜电阻：成本低、精度一般，适合普通电路。
  • 金属膜电阻：精度高、稳定性好，常用于要求较高的电路（如嵌入式开发板）。
  • 贴片电阻：体积小，表面贴装，是 PCB 板上最常见的类型。
  • 可变电阻（电位器）：阻值可手动调节，比如收音机的音量旋钮
  • 三、电阻的读取

二、电容

  • 认识电容
    电容是电子电路中三大基础无源元件之一，核心作用是储存和释放电荷，就像电路里的“小电池”，还能实现滤波、耦合、旁路、谐振等功能。

  • 一、核心原理
    电容由两个相互绝缘的导体（极板）和中间的绝缘介质构成。当两端加上电压时，极板会积累等量异种电荷；断开电源后，电荷会在极板上保存一段时间（理想状态），形成电场。

  • 二、核心参数

  1. 标称容量：电容储存电荷的能力，单位是法拉（F），常用单位为微法（μF）、纳法（nF）、皮法（pF），换算关系：
    1F = 1000000 μF = 1000000000 nF = 1000000000000 pF
  2. 额定电压：电容长期稳定工作允许的最大电压，超过这个值会击穿介质，导致电容损坏。
  3. 介质类型：决定电容的性能和适用场景，常见的有陶瓷、电解、钽电容等。
  4. 精度：实际容量与标称容量的误差范围，普通电容精度 ±20%，精密电容可达 ±1%。

  • 三、电容特性
    电容两端电压不能突变
    $I=C\cdot \mathrm{dU/dt},\quad u=\frac1C \int i\mathrm{d}t$

  • 四、各种电容

三、电感

  • 认识电感
    电感是电子电路三大基础无源元件之一，核心作用是储存磁场能量，能阻碍电流的变化（通直流、阻交流，通低频、阻高频），常用来实现滤波、扼流、谐振、储能等功能。

  • 一、核心原理
    电感的本质是绕在铁芯或磁芯上的线圈。当电流通过线圈时，会产生磁场；电流变化时，磁场也会随之变化，进而在线圈自身感应出反向电动势，阻碍电流的增减——这个特性叫做电磁感应。
    简单类比：电感就像电路里的“惯性元件”，电流想突然变大或变小，它都会“拖后腿”。

  • 二、核心参数
    电感量：衡量电感储存磁场能力的参数，单位是亨利（H），常用单位为毫亨（mH）、微亨（μH）
    换算关系：1H = 1000 mH = 1000000 μH

额定电流：电感长期工作允许通过的最大电流，超过会因发热烧毁线圈，或导致电感量下降。

三、MOS管

  • 1.认识MOS管
  • 2.MOS管等效

  • 1.PMOS（P型MOS管）
    标题：Pmos等效模型
    引脚：G栅极、S源极、D漏极
    等效：S-D之间等效可变电阻R，Rds为漏源电阻

  • 阈值电压 Vgsth < 0（负值）

  • 横轴Vgs（栅源电压）

    • $V_{GS} > V_{gsth}$：Rds无穷大，管子关断
    • $V_{GS} < V_{gsth}$：Rds变小，管子导通

      简单记：PMOS，栅极电压比源极低到一定程度才导通。

  • 2.NMOS（N型MOS管）
    标题：Nmos等效模型
    引脚：G栅极、D漏极、S源极
    等效：D-S之间等效可变电阻R，Rds漏源电阻

  • 阈值电压 Vgsth > 0（正值）

  • 横轴Vgs（栅源电压）

    • $V_{GS} < V_{gsth}$：Rds无穷大，管子关断
    • $V_{GS} > V_{gsth}$：Rds变小，管子导通

      简单记：NMOS，栅极电压比源极高超过阈值才导通。

  • 对比小结

    器件 阈值Vgsth 导通条件
    NMOS 正数 $V_{GS}>V_{gsth}$，G比S电位高
    PMOS 负数 $V_{GS}<V_{gsth}$，G比S电位低

原理：MOS管可以看成电压控制的可变电阻。Vgs改变，漏源之间电阻Rds在极小（导通）和无穷大（断开）之间切换，常用来做电子开关。

  • 3.转移特性曲线

  • 1.输出特性曲线（左图）
    横轴：漏源电压 Uds (V)
    纵轴：漏极电流 Id (mA)
    每条曲线对应不同栅源电压 Ugs

  • 四个工作区域：

  • 截止区：Id≈0，管子关断

  • 可变电阻区：Uds较小时，Id随Uds线性增加，管子等效为可变电阻

  • 恒流区：Uds足够大后，Id基本不变，只受Ugs控制（放大区）

  • 击穿区：Uds过大导致Id急剧增大，管子损坏

  • 关键概念：

  • 预夹断轨迹：各条曲线开始进入恒流区的连线

  • Ugs=10V, 8V, 7V, 6V, 5V, 4V：不同栅源电压下的曲线

  • 2.转移特性曲线（右图）
    横轴：栅源电压 Ugs
    纵轴：漏极电流 Id

  • 特性：

  • Ugs(th)：开启电压（阈值电压）

  • Ugs < Ugs(th)：Id≈0，管子截止

  • Ugs > Ugs(th)：Id随Ugs增大迅速增加

  • 体现了栅极电压对漏极电流的控制能力
